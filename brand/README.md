# ForgePilot brand assets

These files are the source of truth for the ForgePilot visual identity. They are intentionally self-contained SVGs so they can be used in documentation, release pages, social cards, and terminal-adjacent interfaces without a build step.

## Files

- `forgepilot-mark.svg` - standalone FP compass mark. Use at square sizes from 24px upward.
- `forgepilot-wordmark.svg` - mark plus the ForgePilot name for dark surfaces.
- `forgepilot-social-preview.svg` - 1200x630 repository and social preview artwork.

## Visual system

| Token | Hex | Use |
| --- | --- | --- |
| Forge blue | `#2F6BFF` | primary action, compass points, Pilot accent |
| Pilot amber | `#F2B84B` | focus line, approval, compass center |
| Signal mint | `#39D98A` | healthy state and availability signal |
| Graphite | `#10141C` | terminal background and mark counter |
| Frost | `#EEF2F7` | type, outlines, and light surfaces |

## Usage guidance

Use the mark when space is limited or when the product name is already present. Keep clear space equal to the width of the inner amber diamond on all sides. Do not rotate, stretch, recolor, or place the wordmark on a low-contrast background. The supplied wordmark and social preview are designed for Graphite surfaces; for light surfaces, use the mark and set surrounding type to Graphite.

The product name is written as **ForgePilot** with a capital `F` and `P`, without a space or hyphen. The short descriptor is:

> A controlled engineering agent for the terminal.
